# SLAM

围绕同时定位与建图（Simultaneous Localization and Mapping）组织机器人定位和地图构建知识。

## 知识范围

Visual SLAM、Semantic SLAM、Loop Closure。

阅读一个 SLAM 系统时，先梳理传感器输入、坐标系和时间同步，再沿着前端跟踪、后端优化与回环检测理解数据流。

## 阅读入口

关注 Visual SLAM、Semantic SLAM 和 Loop Closure。三维点集的几何处理归入 [点云](../point-cloud/index.md)。
