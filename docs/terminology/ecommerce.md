# 电商与零售 · 面试清单

**面试权重**：★★★★☆　业务岗必考；技术岗也常用它判断「你懂不懂业务」。核心不是背定义，而是**说清口径**。

---

## 一、商品与供给模型

| 术语 | 一句话释义 |
| --- | --- |
| **SPU** | 标准化产品单元，回答「这是什么商品」（如 iPhone 16） |
| **SKU** | 最小库存单元，回答「具体哪一件可售」（iPhone 16 / 256G / 黑色） |
| **SPU-SKU 层级** | 类目 → 品牌 → SPU → SKU；详情页挂在 SPU，库存价格挂在 SKU |
| **属性与规格** | 属性描述特征（材质），规格是可枚举可选项（尺寸），规格组合决定 SKU 生成 |
| **前台类目 vs 后台类目** | 前台类目用于导购（可随季节调整），后台类目用于管理与结算（稳定） |
| **标品 vs 非标品** | 标品可标准化比价（3C、书），非标品（服饰、生鲜）靠内容与信任成交 |
| **组合商品 / 套装** | 多个 SKU 组成一个可售单元，涉及库存分解与扣减顺序 |
| **虚拟商品** | 卡券、会员等无实物库存的商品，履约模型与实物完全不同 |
| **库存三态** | 实物库存、可售库存（扣掉占用）、占用/锁定库存（下单未付款） |
| **超卖 vs 少卖** | 超卖是卖超过库存（体验事故），少卖是库存没卖完（收入损失），靠扣减策略权衡 |
| **库存扣减方式** | 下单扣减（防超卖）vs 支付扣减（降少卖）；高并发下用预占 + 超时释放 |
| **安全库存** | 为需求波动与补货周期预留的缓冲量 |
| **履约** | 从订单生成到送达的全过程：拆单、拣货、发货、配送、签收 |
| **OMS / WMS / TMS** | 订单管理 / 仓内管理 / 运输管理三大系统 |
| **正逆向流程** | 正向是下单到妥投，逆向是退货、换货、退款、售后 |
| **动销率** | 有销量的 SKU 占在售 SKU 的比例，反映选品效率 |

## 二、交易核心指标

| 术语 | 一句话释义 |
| --- | --- |
| **GMV** | 商品交易总额；**口径关键**：含不含未付款、含不含取消退款、含不含运费 |
| **GMV 拆解** | GMV = 流量 × 点击率 × 转化率 × 客单价，是定位增长问题的起点公式 |
| **销售额 / 净成交额** | 通常指扣除退款后的实收，与 GMV 不是一回事 |
| **订单数 vs 销量** | 一个订单可含多个 SKU，两者口径不同、不可直接比 |
| **客单价 AOV** | 平均每单金额 = 销售额 / 订单数，与「件单价」不同 |
| **UV 价值** | 销售额 / UV，衡量单个访客的变现效率 |
| **退货率 / 退款率** | 分母口径要明确：按订单、按件数还是按金额 |
| **复购率** | 统计窗口（30 天 / 90 天）与分母（首购用户）不同，结果能差一倍 |
| **ARPU / ARPPU** | 单用户平均收入 / 单付费用户平均收入 |
| **LTV** | 用户生命周期总价值，必须与 CAC 一起看单位经济模型 |
| **CAC** | 获客成本；LTV/CAC 是业务健康度的常用标尺 |
| **ROI vs ROAS** | ROI 是投入产出（可用利润口径），ROAS 专指广告花费回报（收入口径） |
| **库存周转天数** | 库存 / 日均销量，电商与零售的核心运营效率指标 |
| **履约时效** | 下单到签收的时长，常以 24h/48h 达成率考核 |
| **GPM** | 千次曝光成交额，常用于直播间之间的效率横向对比 |

## 三、流量与转化漏斗

| 术语 | 一句话释义 |
| --- | --- |
| **PV** | 页面浏览量，含同一用户的重复访问 |
| **UV** | 独立访客数，按去重口径（设备 / 账号 / IP）统计 |
| **曝光 Impression** | 内容或商品被展示的次数，是漏斗的最上层 |
| **点击率 CTR** | 点击 / 曝光，衡量素材与位置的吸引力 |
| **转化率 CVR** | 成交 / 上层流量，**必须绑定漏斗层级**才有意义 |
| **加购率 / 收藏率** | 中间意向指标，用于定位「有兴趣但没买」的卡点 |
| **支付转化率** | 支付订单 / 下单订单，反映支付环节的流失 |
| **转化漏斗** | 曝光 → 点击 → 详情 → 加购 → 下单 → 支付 → 履约，逐层定位流失点 |
| **漏斗归一化** | 每层用上层量作分母，才能横向比较不同环节的流失率 |
| **跳失率 / 跳出率** | 只访问一个页面就离开的比例，反映落地页与流量的匹配度 |
| **人均访问深度** | 单用户浏览页面数，衡量「逛」的意愿 |
| **停留时长** | 内容质量与导购效率的辅助指标，需与转化交叉验证 |
| **流量结构** | 自然、搜索、推荐、广告、私域的占比，决定增长能否持续 |
| **A/B 实验** | 分组对照验证改动的真实增量；要关注分流均匀、样本量、显著性 |
| **同期群 Cohort 分析** | 按获客批次跟踪行为变化，是识别留存趋势的标准方法 |

## 四、用户、人群与留存

| 术语 | 一句话释义 |
| --- | --- |
| **新客 / 老客** | 以是否首次成交区分；老客的运营目标是复购与提频 |
| **留存率** | 次日 / 7 日 / 30 日仍活跃或仍购买的比例，是产品市场契合度的关键证据 |
| **流失与召回** | 一段时间未活跃即定义为流失；召回靠权益、短信、Push |
| **RFM 模型** | 用最近购买时间、购买频次、购买金额对用户分层 |
| **用户分层** | 按价值与生命周期分层运营，粗放补贴是最大的浪费 |
| **AARRR 模型** | 获取 → 激活 → 留存 → 变现 → 传播的海盗指标框架 |
| **用户画像与标签体系** | 事实标签 + 模型标签 + 规则标签，是精准运营的基础设施 |
| **人群包** | 按标签圈定的人群集合，用于投放、触达与实验 |
| **私域** | 企业可反复免费触达的用户池（企微、社群、公众号） |
| **公域 / 私域 / 商域** | 平台自然流量 / 自有可控流量 / 付费商业流量 |
| **会员体系** | 用分层权益换取长期复购与更高客单价 |
| **积分与权益** | 行为激励工具，要核算成本并防刷量 |
| **NPS** | 净推荐值，衡量口碑与长期体验 |

## 五、营销与广告投放

| 术语 | 一句话释义 |
| --- | --- |
| **CPM** | 按千次曝光计费，适合品牌曝光 |
| **CPC** | 按点击计费，适合效果引流 |
| **CPA / CPL** | 按行动 / 线索计费，把成本风险转移给平台 |
| **CPS / 佣金** | 按成交计费，达人分销常用 |
| **OCPX** | 平台按目标（成交、ROI）自动出价与投放的智能模式 |
| **ROAS** | 广告花费回报 = 广告带来的收入 / 广告花费 |
| **出价与扣费** | 常见为广义二价机制，出价不等于实际扣费 |
| **归因窗口** | 用户看到广告后多久内的成交算这次广告的功劳；窗口不同 ROAS 天差地别 |
| **归因模型** | 首次 / 末次 / 线性 / 时间衰减 / 数据驱动，决定功劳如何分配 |
| **增量归因** | 用实验或对照组剥离「本来就会买」的部分，是归因的进阶做法 |
| **拉新 vs 收口** | 新客成本高但带来增量，老客转化高但可能本就是自然流量 |
| **投放 ROI 的常见坑** | 把自然流量算进广告效果、不看退款率、不看长期 LTV |
| **人群定向与 Lookalike** | 平台标签定向与相似人群扩展，受隐私政策与合规限制 |

## 六、运营与内容电商

| 术语 | 一句话释义 |
| --- | --- |
| **人货场** | 用户、商品、场景三要素的匹配，是零售分析的基本框架 |
| **人货匹配** | 用推荐与标签把对的货推给对的人，是平台效率的核心 |
| **直播三率** | 曝光-点击率、点击-成交率、UV 价值，判断直播间效率 |
| **达人分销 / 联盟** | 借助外部流量与信任背书分成带货 |
| **种草与拔草** | 内容侧激发兴趣（种草），交易侧完成转化（拔草） |
| **内容场 vs 交易场** | 「逛」的心态与「买」的心态，流量分发逻辑截然不同 |
| **货架电商 vs 兴趣电商** | 以主动搜索成交为主 vs 以推荐激发需求为主 |
| **大促节奏** | 预热蓄水 → 开售爆发 → 返场，各阶段的目标与指标不同 |
| **坑产** | 单个商品位或单场直播贡献的成交额 |
| **价格带与价格力** | 商品在价格区间中的竞争力，常是流量分配的重要因子 |
| **SKU 效率** | 单 SKU 的动销与贡献，长尾 SKU 会拖累库存与运营成本 |

## 七、口径陷阱速记

| 术语 | 一句话释义 |
| --- | --- |
| **GMV 含未付款** | 行业惯例多含「拍下未支付」，与销售额对比时极易误判 |
| **复购窗口不一致** | 30 天复购与 90 天复购是两个不同指标，不可混用 |
| **ROI 分子口径** | 用收入还是利润、含不含退款，能算出相差一倍的结论 |
| **退货率分母** | 按订单、按件数、按金额三种算法结果差异明显 |
| **UV 去重口径** | 按设备、按账号、按 IP 去重，数值差别很大 |
| **「转化率」不写层级就是废话** | 曝光→点击、点击→成交是两个不同的转化率 |
| **数据可比性** | 大促期与非大促期、不同渠道与不同口径的数据不能直接比 |
| **正确做法** | 每个指标维护一份「口径字典」并落进数据资产，而不是靠口头约定 |
