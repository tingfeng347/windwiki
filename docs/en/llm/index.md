# LLM

Knowledge across the engineering path from model architecture to inference serving for large language models.

## Scope

Transformers, inference, fine-tuning and serving.

Separate model capability from system capability: architecture, training data and fine-tuning set the capability boundary; inference, quantization, batching and caching drive serving cost and latency.

## Start here

Focus on Transformers, inference optimization, fine-tuning and model serving. When a specific configuration is involved, record the model version, hardware and evaluation conditions.

Formula example: $E = mc^2$.
