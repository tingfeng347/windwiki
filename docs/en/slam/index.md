# SLAM

Robot localization and mapping knowledge around Simultaneous Localization and Mapping.

## Scope

Visual SLAM, semantic SLAM and loop closure.

When reading a SLAM system, first map out sensor inputs, coordinate frames and time synchronization, then follow front-end tracking, back-end optimization and loop closure to understand the data flow.

## Start here

Focus on Visual SLAM, semantic SLAM and loop closure. Geometric processing of 3D point sets belongs to [Point Cloud](../point-cloud/index.md).
