# Computer Vision

Computer vision knowledge from image input to usable visual output.

## Scope

Detection, segmentation, depth and 3D vision.

Define the task's input and output first: detection answers where targets are, segmentation describes pixel ownership, and depth estimation plus 3D vision handle spatial relations.
