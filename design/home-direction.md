# WindWiki 首页视觉与动效

参考：[Yuxi](https://xerrors.github.io/Yuxi/)、[OpenDesign](https://open-design.ai/zh/)。参考的是分栏展示、悬浮导航、内容预览切换和滚动节奏；图形、文案与组件围绕 WindWiki 的知识目录独立实现。

## 设计方向

把首页做成一张可以探索的知识工作台。首屏同时看到标题与玻璃风带，接下来沿技术主题、学习路径、工程专题和知识星图逐层展开。

色板：云白 `#f5f7fb`、深海蓝 `#18354a`、钴蓝 `#4967eb`、薄荷绿 `#c7e9dc`、薰衣草紫 `#dccdf5`、杏橙 `#ffd5b8`。深色模式用深蓝背景和独立的文字、边框与专题配色。

字体：中文采用 Noto Sans SC、PingFang SC、Microsoft YaHei 的系统回退；大标题用紧凑字距和明确的两行结构。英文品牌采用 Arial 系列的粗体，代码预览保留等宽字体。无需在线字体请求。

版式方案：

```text
方案 A：居中标题 + 通栏艺术图
        标题 / 按钮
     大幅图像 / 学习路径

方案 B：分栏首屏 + 内容工作台（采用）
     标题 / 按钮   艺术图 / 概念节点
     ← 技术主题滚动带 →
           理解与连接
     固定路径图     三阶段介绍
     专题切换 / 工程流程预览
     三个实用入口 / 知识星图 / 页尾
```

标题与正文左对齐，介绍文字居中收拢，专题区域保持统一的阅读起点。用不同尺度区分主视觉、工程预览和实用入口。

## 设计审查

将起初考虑的通用玻璃卡片改成带有知识含义的节点和流程：首屏围绕 Python、RAG、Agent 形成连接；专题直接展示检索、执行和训练的工程概念。主视觉沿用原创玻璃风带，不使用参考站点的插画、截图或品牌资源。数字只用于确实存在先后关系的三个学习阶段。

## 动效与边界

- 首屏只有一次协调的文字显现；艺术画布随鼠标轻微转动、随滚动展开，触屏不启用鼠标跟随。
- 技术主题带匀速滚动，悬停、键盘聚焦或触摸暂停。装饰性副本不进入键盘和读屏顺序。
- 介绍文字随滚动加深，学习路径按当前阶段高亮；内容不会因动画未执行而隐藏。
- 专题支持鼠标与键盘切换，展现不同工程流程；没有 JavaScript 时仍可看到全部专题和链接。
- 星图接近视口才加载；离屏与页面不可见时停止动画。尊重 `prefers-reduced-motion`。
- 保留 Rspress 默认主题，以 `pageType: home`、全局样式和全局组件实现；文章阅读与原有导航行为不变。
